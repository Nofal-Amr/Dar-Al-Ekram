# دار الإكرام — نظام إدارة الحالات والصرف

موقع ثابت (HTML + JS modules) شغال على Supabase. مفيش build ولا npm في التشغيل.

## الرفع
الريبو متوصل بـ Vercel، وأي push على `main` بينزل على الموقع لوحده (Framework: **Other**).
ملف `.vercelignore` بيمنع رفع ملفات التجربة والاختبارات.

## أول مرة
افتح الرابط ← هيطلب منك تعمل **حساب المدير** (اسمك + رقم تليفونك + رقم سري).
بعد كده من **الإعدادات → إضافة موظف** تعمل حسابات الموظفين.

## التطبيق على الموبايل
Chrome ← ⋮ ← «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية».

## التطوير
- `app.js` الشاشات · `core.js` المنطق (عليه اختبارات) · `icons.js` الأيقونات · `demo.js` بيانات وهمية للتجربة
- الاختبارات: `npm test` (Node 20+)
- التجربة على الجهاز: شغّل السيرفر المحلي وافتح `http://localhost:5173/?demo`
- المكتبات والخطوط في `vendor/`، بإصدارات ثابتة (supabase-js 2.117.1، SheetJS 0.18.5)
- لازم يشتغل على **Chrome 109** (آخر نسخة بتشتغل على ويندوز ٧)
- التغييرات: `CHANGELOG.md` · أبحاث التصميم: `docs/research/`
