# دار الإكرام — نظام إدارة الحالات والصرف

موقع ثابت (HTML + JS modules) شغال على Supabase. مفيش build ولا npm في التشغيل.

## الرفع
الريبو متوصل بـ Vercel، وأي push على `main` بينزل على الموقع لوحده (Framework: **Other**).
ملف `.vercelignore` بيمنع رفع ملفات التجربة والاختبارات.

## أول مرة
افتح الرابط ← هيطلب منك تعمل **حساب المدير** (اسمك + رقم تليفونك + رقم سري).
بعد كده من **الإعدادات → إضافة موظف** تعمل حسابات الموظفين.

## التطبيق على الموبايل
- **أي موبايل:** Chrome ← ⋮ ← «تثبيت التطبيق»، أو من الإعدادات ← «ثبّت التطبيق». على الآيفون: Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية».
- **تطبيق أندرويد (APK):** `org.daralekram.app`، مبني بـ Bubblewrap (Trusted Web Activity). بيفتح الموقع ملء الشاشة، وكل تحديث للموقع بيوصل للتطبيق لوحده.
  - المشروع ومفتاح التوقيع في `../android/` **برّه الريبو**. **ماترفعش `android.keystore` ولا `SIGNING-KEY-KEEP-SAFE.txt` على GitHub**، وخلّي منهم نسخة احتياطية.
  - `.well-known/assetlinks.json` هو اللي بيربط الموقع بالتطبيق. لو المفتاح اتغير، لازم الملف ده يتحدث بالبصمة الجديدة.
  - إعادة البناء: `gradlew assembleRelease` جوه `../android` (بـ JDK بتاع Android Studio، ومعاه `JAVA_TOOL_OPTIONS=-Djdk.net.unixdomain.tmpdir=C:\gtmp`)، وبعدين `zipalign` و`apksigner` بالمفتاح.
